# Security policy

## Report a vulnerability

Use GitHub private vulnerability reporting. Open the "Security" tab of
https://github.com/dectria-GmbH/identkit and choose "Report a vulnerability".

Do not open a public issue or pull request for a vulnerability.

## Supported versions

Only the latest released version receives security fixes.

## Scope

identkit is a library for sign-in, sessions and approval evidence. A report is in scope if it
shows a way to bypass authentication, step-up or approval checks, to read or forge a session or
token, or to leak secrets through the library.
